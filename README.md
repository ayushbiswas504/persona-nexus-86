# Future CEO Portfolio

Create a premium personal portfolio website for a young CEO, software developer and AI enthusiast. Use a dark futuristic aesthetic, smooth animations, glassmorphism, interactive project cards, an impressive hero section, experience timeline, technical skills, achievements, leadership section, GitHub integration, LinkedIn integration, contact section and downloadable resume. Make it highly responsive and recruiter-friendly. Use Next.js, TypeScript, Tailwind CSS and modern animations. Keep the design minimal, premium and not overly flashy
